# 实测数据（ESP32-P4 + 自训练 q3e4）

> 生成于 2026-11-06 凌晨。模型：自训练 `full_sft_768.pth` → HF → q3e4（SHA256 `feb574f9…`，28,632,448 B）。
> 设备：ESP32-P4 rev v1.3，360 MHz，16 MB flash / 32 MB PSRAM。

## 1. 速度 / GEMV / 带宽

| 配置 | ms/token | tok/s | GEMV ms/token | r | 累计加速 |
|---|---|---|---|---|---|
| 标量 float，展开权重（历史基线） | 5,622 | 0.178 | — | — | 1× |
| int16 激活 + 零拷贝打包 | 2,639 | 0.379 | 2,607 | 0.988 | 2.13× |
| + 激活量化外提 / offset 消除 | **2,152** | **0.465** | **2,120** | **0.985** | **2.61×** |
| q2 模型（同 kernel） | **1,352** | **0.740** | 1,216 | 0.899* | — |
| mixed 模型（同 kernel） | **2,017** | **0.496** | 1,860 | 0.922* | — |

\* r 为 lm_head 未计入的 GEMV 口径；q3e4 的精确 r 由 r-instrumented 固件测量（见日志 `measure_q3e4_r.log`）。

- **PSRAM 顺序读带宽**：`/bw` 1 MB 顺序读 → **95.9 MB/s**（下界）。\n\n- 精确 r（含 lm_head）：**0.985**（GEMV 2,120 ms/token）。
- 优化后 GEMV 有效权重流量：28.63 MB / 1.994 s ≈ **14.4 MB/s**（约为带宽下界的 16%）。
- 每 token 总流量（权重 + 一次完整 KV pass 2.36 MB）≈ 30.99 MB。

## 3b. KV cache FP16 / 192-token（2026-11-06 实测）

- 将 K/V cache 改为 FP16 存储，上下文 96→**192 token**，KV 占用仍为 **2,359,296 B**；
- window0 CE：**6.660667**（FP32-96 为 6.662094，Δ=0.00143，0.02%）；
- 速度：**2,153.9 / 2,154.3 ms/token**（r=0.984），与 FP32-96 的 2,152 在噪声内；
- 结论：同预算下上下文翻倍、代价可忽略；部署配置采用 192 token + FP16 KV（FP32-96 保留为保守回退）。

## 3c. 192-token 上下文收益

- `/pplw 192`：单窗口 192 token → **CE 5.970078（PPL 391.5）**；
